# claudemodz/mods

Claude Code mods we use every day. Each one is reviewed, tested and MIT-licensed.
Requires Claude Code 2.1.287 or later.

```
/plugin marketplace add claudemodz/mods
/plugin install <mod>@claudemodz-mods
```

| Mod | What it does |
|---|---|
| [no-attribution](plugins/no-attribution) | Removes Claude's commit trailer and PR footer, or replaces them with your text |
| [model-router](plugins/model-router) | Runs Explore subagents on Haiku; /router switches the main model |
| [ci-pane](plugins/ci-pane) | Live PR checks in a pane, with re-run failed and a failing-only status line |
| [standup](plugins/standup) | Logs your work across sessions; /standup writes the update |

Unofficial community project, not affiliated with Anthropic. Mods run with your permissions — read a mod's README and run `claude plugin validate plugins/<mod>` to see exactly what it can do.
